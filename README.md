# Trip Replanner

A trip workspace for travellers whose day in Đà Lạt is broken by rain. Tell it what changed in plain language and an LLM agent re-plans the rest of the day around the bookings you cannot move, such as the sleeper bus home, using checked opening hours and real travel times. A code validator rejects any plan that breaks a hard constraint, and nothing changes until you accept the diff.

Course project for CSC13114 Advanced Web Development, HCMUS.
