# Trip Replanner

A trip workspace for travellers mid-trip whose day just broke: rain, a delayed train, or a change of mind. Tell it what changed in plain language and an LLM agent re-plans the day around the bookings you cannot move, using real opening hours and travel times. Every proposal is shown as a diff with what each change costs (for example a non-refundable ticket you would lose) and nothing changes until you accept it.

Course project for CSC13114 Advanced Web Development, HCMUS.
